# Gateway lifecycle. (1) A service restart (what an admin Stop→Start or config change does): the OLD
# socket's close callback still runs scheduleReconnect() on the shared DiscordBotState, so the status
# the admin tab shows can flip to RECONNECTING while the new connection is healthy.
# (2) A server-side drop: the bot should RESUME and keep answering.
